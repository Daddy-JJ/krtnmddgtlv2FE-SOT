# Contributing

## Branching
`main`, `develop`, `feature/<name>`, `fix/<name>`.

## Commit convention
`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`.

## PR checklist
- Scope sesuai SSOT
- Migration bila schema berubah
- OpenAPI bila API berubah
- Test ditambahkan
- Tidak ada secret
- Security checklist lulus
- Decision Log diperbarui bila perlu
